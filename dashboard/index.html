需要注意的地方

    軍事單位與克制

    依當時還活著的兵種數量，計算誰的兵更能克制對方。高於 0 代表我方佔優。

    勝負關鍵指標

    這場在各項指標上你是領先還是落後（組隊時對手取平均）。

    整場統計

    我（藍）與對手（紅，組隊時為平均）。

    關鍵時間點

    每格是「我 / 對手」，顏色代表誰佔優。

    玩家

    領先時與落後時的勝率

    每一列是一個指標：綠點是你在該指標領先對手時的勝率，紅點是落後時的勝率。兩點距離越遠，這個指標越能決定你的勝負。

    比較方式：1v1 直接和對手比；組隊時和所有對手的平均比。對局在檢查時間點之前就結束的場次，不列入該項。分數（總分、軍事分等）是遊戲內建的計分。

    戰術模擬需要透過網站開啟（直接點開 HTML 檔時無法使用）：在 aoe4-frontend 執行 npm run dev，再開 http://localhost:5173/ 。

    看誰的戰績

    用 AoE4 World 搜尋

    輸入遊戲裡的名稱，或 AoE4 World 的玩家 ID（aoe4world.com/players/ 後面的數字）。只有線上配對與排位的場次；資料會存在這個瀏覽器，下次打開不用重抓。

      讀取這台電腦的 AoE4 對局

      選擇 文件 → My Games → Age of Empires IV 資料夾（也可以選上層的「文件」）。自訂、對電腦和在這台電腦打的線上對局都讀得到，含逐時數據；遊戲只保留最近一段時間的檔案。檔案只在你的瀏覽器裡解析，不會上傳。
