# AoE4 儀表板資料格式（version 1）

儀表板 `index.html` 讀取一個 JSON 物件。之後寫 API 程式時，只要產生這個格式即可，有三種接法：

1. **覆寫檔案**：寫入 `data/aoe4-data.js`，內容為 `window.AOE4_DATA = { ...JSON... };`，重新整理網頁即可。
2. **API 網址**：在 `index.html` 上方把 `AOE4_CONFIG.dataUrl` 設成 API 網址（回傳純 JSON），`refreshMinutes` 設定自動更新間隔。網頁是用檔案開啟時，API 伺服器要回傳 `Access-Control-Allow-Origin: *`。
3. **手動匯入**：網頁右上角「匯入資料」選 `.json` 或 `.js`，或直接拖進視窗。

另外網頁提供 `window.AOE4Dashboard.load(資料)`，可由其他程式碼直接推送資料。

## 從 aoe4world 取得資料（給之後的 API 程式參考）

| 用途 | 網址 |
|---|---|
| 玩家資料與目前分數 | `https://aoe4world.com/api/v0/players/{profile_id}` |
| 對局清單（每頁 50 場，依 `next_page` 翻頁） | `https://aoe4world.com/api/v0/players/{profile_id}/games?limit=50&page=1` |
| 單場詳細摘要（逐時數據） | `https://aoe4world.com/players/{profile_id}/games/{game_id}/summary?camelize=true` |

- 對局清單的 `teams` 是 `[[{player:{...}}]]`，每位玩家包在 `player` 裡。
- 摘要不需要 API key；自訂對局通常回傳 404。
- `villagers`、`army` 由摘要的 `buildOrder`（每種單位的 `finished`／`destroyed` 時間）推算存活數量；`army` 不含村民、偵察兵、僧侶、商人與漁船。
- 舊版摘要沒有 `*Gathered` 欄位，可用 `*PerMin` 以梯形法積分估算，並把 `gatheredEstimated` 設為 true。
- 每個請求之間間隔 1 秒以上，已下載的摘要存起來不要重複抓。
