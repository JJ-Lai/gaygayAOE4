# Phase 5：優化與擴充

| 項目 | 內容 |
|------|------|
| 預估時間 | 持續進行 |
| 前置條件 | Phase 4 完成（MVP 可上線） |

| 狀態 | ⬜ 未開始 |

## 目標

提升效能、可靠性與功能完整度，並視需求擴充分析維度與部署方式。

## 任務清單

### 效能優化

- [ ] 分析常用查詢的 SQL 執行計畫檢視
- [ ] 新增複合索引（profile_id + civ + started_at 等）
- [ ] 建立預聚合表：
  - [ ] `agg_player_civ_stats`（玩家×文明勝率）
  - [ ] `agg_matchup_matrix`（文明對戰矩陣）
  - [ ] `agg_resource_timeline`（平均資源曲線）
- [ ] 排程定期刷新預聚合表
- [ ] API 回應快取（短期，例如 5 分鐘）
- [ ] 前端圖表資料懶加載 / 虛擬化長列表

### 資料庫遷移（視需要）

- [ ] 評估 H2 資料量與查詢效能瓶頸
- [ ] 若需要：建立 PostgreSQL 遷移方案
- [ ] 抽象資料源設定（H2 / PostgreSQL 可切換）
- [ ] 資料遷移腳本

### 同步可靠性

- [ ] 同步失敗重試機制（dead letter queue）
- [ ] 同步狀態 Dashboard（管理用）
- [ ] 告警：連續 N 次同步失敗時通知
- [ ] 支援多 profile_id 批次追蹤清單
- [ ] 使用者「我的最愛玩家」功能（localStorage 或帳號）

### 功能擴充

- [ ] 支援更多模式（qm_2v2, rm_2v2 等）
- [ ] 地圖維度分析頁
- [ ] 補丁版本比較
- [ ] Rating 區間篩選
- [ ] 匯出功能（CSV / JSON）
- [ ] 比較模式：兩個 profile_id 並排分析
- [ ] 私人對戰：使用者輸入 `api_key` 設定頁

### 搜尋體驗強化

- [ ] 玩家名稱搜尋（`GET /players/search?query=`）
- [ ] 搜尋建議 / Autocomplete
- [ ] 最近搜尋紀錄（localStorage）
- [ ] 分享連結：`/player/10861747/resources?civ=en`

### 軍事分析深化

- [ ] `fact_military_loss` 表實作與填充
- [ ] 單位層級損失統計
- [ ] 軍事分數 vs 對手文明熱力圖細化

### 維運與部署

- [ ] Docker Compose（後端 + H2 volume + 前端）
- [ ] 生產環境 `application-prod.yml`
- [ ] 日誌集中（JSON 格式）
- [ ] 健康檢查與 metrics（Micrometer / Prometheus）
- [ ] 備份策略（H2 檔案定期備份）

### 測試與品質

- [ ] 提高單元測試覆蓋率
- [ ] 整合測試 CI 流程
- [ ] E2E 測試（搜尋 → 儀表板完整流程）
- [ ] 負載測試（模擬多使用者查詢）

### 文件

- [ ] 部署指南 `docs/DEPLOYMENT.md`
- [ ] API 變更紀錄
- [ ] 使用者操作說明（如何找 profile_id）
